# Full loop: mine an asteroid, sell the ore, buy a module, found a colony.
new 11
tutorial off

# 1. Mine: the laser fills the hold with ore from the asteroid.
near asteroid
hold v 20
expect cargo iron > 0

# 2. At the station: dock, sell the selected resource (iron is the first one).
near station
key d
expect docked yes
expect screen station
key enter
expect cargo iron < 1
expect credits > 500
print

# 3. Buy a module: ship screen, step to an empty slot, picker, first compatible module.
give credits 500000
key h
expect screen ship
print
key down
key down
key down
key down
key down
key down
key down
key down
key down
key enter
key enter
print
expect credits < 1000000
key escape
key escape
key u
expect docked no

# 4. Found a colony on a planet with a full kit.
give cargo construction_materials 3000
give cargo colonists 400
give cargo food 300
give cargo water 600
near planet
key o
expect colonies > 0
print
